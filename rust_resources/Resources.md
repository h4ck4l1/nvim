# BISMILLAH

## Beginner

1. [Rustlings](https://github.com/rust-lang/rustlings/)
This is arguably *THE* starting point of any rust beginner, You have this alongside [The Rust Book](https://doc.rust-lang.org/book/) to solve the questions exercise by exercise, You'll start to get the basic concepts

2. [Rust Exercises](https://rust-exercises.com/100-exercises/)
My Best Go To For Rest Fresh Up. This is next level to Rustlings where the author goes through some indepth and complex exercises than just basic rustlings and ends with http server

## Intermediate

3. [Rust Tracks](https://exercism.org/tracks/rust)
This is an Intermediate Course on Rust that has good hand picked exercises for better understanding of all things rust. This is by far the largest exercise compilation of Rust.

4. [Rust Design Patterns](https://rust-unofficial.github.io/patterns/)
This is a LowLevel book on rust implementation of different design patterns, This is recommended if you want to tackle LowLevel side of rust which most do, unlike me who's only into Web side of things.

## Advanced

5. [The Rustonomicon](https://artur-sulej.github.io/rust-ebooks/rustonomicon.pdf)
This is an extensive book on one of the aspects of Rust which makes Rust, Rust. Deals with all kind of unsafe features of Rust, which is essential for DSA.

6. [The Libble Book on Rust macros](https://lukaswirth.dev/tlborm/)
This is an introduction and application level book on Rust Macros, which are an essential part of abstraction concept of Rust. Most probably one the powerconcepts in Rust.

## Resources and Documentation

7. [Rust by Example](https://doc.rust-lang.org/rust-by-example/)
This is a Go To documentation for std crate features where you have examples on how to use primitive features in different ways like if, if let, match, while, while let etc.,

8. [Lib.rs](https://lib.rs)
This is a catalog of all the rust libraries that are published to crate.io, Every library has its pros and cons, you can check them with LLM, an older lib/crate might have more lowlevel control while newer might have more features and so on

9. [Docs](https://docs.rs)
This is My Favourite Part of Rust Documentation, As I deal in Web side of rust you will be dealing in all kinds of libraries and understanding what is implemented how and where and trait defs, struct names, implicit conversions etc., of your libraries features, you can search and find what you want here, Just type <crate_name> rust docs and you can see all the methods, structs, enums, traits and most importantly features that rust library has to offer.
