# Enable Terminal Visual Effects in PowerShell

## Paste the Shader File in C:/Shaders/RetroNoLines.hsl

## Open Settings (Ctrl + ,) and Open the Json Settings

## In the Default section of the Json

```json

"default": {
"experimental.retroTerminalEffects": true,
"experimental.pixelShaderPath": "C:/Shaders/RetroNoLines.hsl"
}

```
